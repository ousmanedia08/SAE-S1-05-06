Qui sommes-nous ?

Un groupe au cœur du jeu vidéo

VirtualCore est un groupe d'étudiants réunis autour d'une même passion : le jeu vidéo. Pour ce projet, nous avons choisi d'étudier Gameloft, l'entreprise française fondée par Michel Guillemot qui s'est imposée comme un acteur majeur du jeu mobile dans le monde.

Chaque membre du groupe s'est spécialisé dans un domaine : l'histoire, les produits, l'écologie et les finances. Le résultat : une vision complète et détaillée de l'entreprise.
